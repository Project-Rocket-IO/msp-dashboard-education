## Contributing

Naming convention for branches is as follows:

Your branch name should be in the format of ticket number followed by a hyphen and a description in snake case.

For example, if you are working on ticket #88 with description "Set Field for Client", your branch name should be `88-set-field-for-client` or `88-setfieldforclient`.

You should branch off of the `development` branch and make Pull Requests to the `development` branch. 
You need at least one reviewer to approve the PR before it can be merged into `development` (To be decided).

You're not allowed to do anything with `main` branch at all.

Pull Requests should be small and easy to review.

### General Guidelines

- Use `# TODO` comments extensively to track pending work
- Do not leave commented-out code without an accompanying TODO
- Remove unused code before committing
